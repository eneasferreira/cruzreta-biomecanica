# Cruzreta - Informatica Biomecanica

## Descricao do projeto

Este projeto apresenta scripts desenvolvidos em Python
para realizar calculos geometricos de reconstrucao
tridimensional de pontos, utilizando coordenadas de
cameras e suas respectivas projecoes.

## Script 1 - Planilha original

Arquivo: Script_cruzxeta_EneasIBM.py

Este script foi desenvolvido para reproduzir os calculos
apresentados na planilha cruzreta.xlsx, disponibilizada
no MOODLE.

## Script 2 - Dados obtidos em aula

Arquivo: Script_cruzreta_dados_aula.py

Este script utiliza as coordenadas das cameras C1 e C2
e das projecoes P1 e P2, obtidas durante a atividade
pratica realizada em sala de aula.

O programa calcula uma estimativa da posicao
tridimensional e compara os resultados com as
coordenadas medidas utilizando um aparelho a laser.

## Objetivo

Compreender a aplicacao de calculos geometricos na
reconstrucao tridimensional e utilizar a linguagem
Python para automatizar os procedimentos matematicos.
